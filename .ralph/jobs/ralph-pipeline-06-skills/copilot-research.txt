### Codebase Architecture

This is a pnpm monorepo with root Node ESM scripts under `scripts\lib\` and a Vite/React/TypeScript dashboard package under `tools\overview-viewer\`. The Ralph overview pipeline is mostly script-side `.mjs` modules that emit sidecars into `plans\`, while the UI consumes `window.OVERVIEW_DATA` and `window.OVERVIEW_RALPH_STATE`.

Key tools: `pnpm`, Vitest, TypeScript, Vite, React 19. Root tests currently live adjacent to modules as `scripts\lib\*.test.mjs`, not under `scripts\lib\__tests__\`.

### Feature-Relevant Code

- `scripts\lib\derive-ralph-stage.mjs` is the direct model for the new pure predicate module. It exports the canonical stage derivation and already includes all 10 stage values, including `replan-pending`.
