**Technical Constraints**

Do not add a new protocol type: the existing `ResponseEvent` and `ResponseItem` shapes are sufficient.

Do not add a redundant feature gate: chat capture is already reached only through `WireApi::ChatCompletions`, which is gated by `Feature::AnthropicModels`.

Reasoning item ordering is load-bearing: open reasoning item, stream `ReasoningContentDelta`, close reasoning item before opening the assistant message item.

Overlay cannot depend on `codex-api`; it deliberately emits neutral `ChatStreamEvent`s to avoid a Cargo cycle. Core owns `ResponseEvent` mapping.

Replay is the scoped overlay exception. It needs a `// SANDBOX PATCH:` marker plus `docs/implementation/patch-surface.md` §14 invariant and §15 replant note.

The field shape for replay is not knowable from this code; the external 2-turn probe must decide it before changing `payload.rs`.

**Implementation Suggestions**

2. In `anthropic_sse.rs`, add `TranslatedSseEvent::ReasoningDelta(String)` and decode `choices[0].delta.reasoning_text` before checking whether `delta.content` is an array. Skip empty reasoning chunks.

5. In `payload.rs`, add a `"reasoning"` arm in `push_chat_message` that extracts stored `ReasoningText` content and emits the probe-approved chat message shape. Keep it plaintext-only and ignore `encrypted_content`.
