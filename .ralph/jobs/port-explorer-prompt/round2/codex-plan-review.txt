### Feasibility

[High] Previous F-011 is not fully fixed. The plan’s path convention says codex-worktree-relative paths drop only `codex/`, but many implementation paths still incorrectly start at `core/src/...`. Use a path-scoped stash such as `git stash push -m "stash-before-explorer-pointer-bump" -- codex`, and do not use `-u` unless the exact untracked pathspec is intentional.

[Medium] Previous F-002 is only partially fixed.
