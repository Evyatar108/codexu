**Codebase Architecture**

The codex target is a Rust workspace under `codex/external/repos/codex-patched/codex-rs`, with fork-only overlay crates included from `codex/codex-rs-overlay` via relative workspace members. Key crates for this work are:

- `features`: canonical feature registry, TOML parsing, defaults.
- `config` + `core`: config schema/loading and resolved runtime `Config`.
- `cli`: `--enable/--disable` feature override surface.
- `tui`: `/experimental`, model picker, style, paste handling.
- `model-provider`: Copilot/Anthropic catalog and transport gating.
- `app-server` / `app-server-protocol`: app-facing feature catalog and config writes.
- Overlay crates: `codex-copilot`, `codex-copilot-launcher`, `codex-invariant-tests`.

Fork rule: upstream-canonical edits under `external/repos/codex-patched/codex-rs` need `// SANDBOX PATCH:` markers plus registration in `codex/docs/implementation/patch-surface.md`.

**Technical Constraints**

Every migrated behavior must be a `Feature` row with `default_enabled: false`. Plain booleans need no extra config schema because `FeaturesToml` flattens unknown feature keys into `[features]`.

Stage choice matters: `Stage::Experimental` appears in `/experimental`; `UnderDevelopment` is configurable but hidden. Use `Experimental` for user-facing toggles unless intentionally hidden.

Do not keep dual sources of truth. Compatibility aliases are acceptable only if they collapse into `features.<key>` before runtime behavior reads them.

Patch-surface bookkeeping is currently known stale; coordinate with `codex-patch-surface-divergence-registry-refresh`.

**Implementation Suggestions**

Priority 1: Anthropic. Keep `Feature::AnthropicModels` as sole source. Deprecate launcher `enable_anthropic`; during transition, map it to a `-c features.anthropic_models=<bool>` override or warning, not `CODEX_ENABLE_ANTHROPIC`. Keep `--enable-anthropic` only as a CLI alias because it already folds into the feature override. Fix the persisted Claude bug by honoring the gated `bootstrap.default_model` when `config.model` is no longer in `available_models`, or by clearing/resetting the persisted model with an explicit message.

Priority 2: Paste. Add a positive default-off feature such as `legacy_paste_burst_heuristic`. Resolve `Config.disable_paste_burst = !features.enabled(...)`. Temporarily translate legacy top-level `disable_paste_burst=false` to feature enabled and `true` to feature disabled, with docs. Do not touch bracketed paste.

Priority 3: Style. Add `user_message_styling` default-off. Replace env caching with a TUI/runtime setting derived from `config.features.enabled(...)`. Deprecate launcher `style_user_messages`; if retained temporarily, translate it into `features.user_message_styling`.

Tests to plan: feature registry default-off tests, CLI alias tests, launcher deprecation tests, TUI bootstrap persisted-Claude regression, paste config-resolution tests, style feature gate tests, plus invariant tests for new fork feature rows and patch-surface coverage.
