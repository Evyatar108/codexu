### Codebase Architecture

`D:\harness-efforts\codexu` is a pnpm monorepo fork of `slopus/happy`, with TypeScript/React Native/Node packages under `packages/`, orchestration/docs under `plans/`, `.ralph/jobs/`, `tasks/`, and repo-specific guidance in `AGENTS.md` plus `docs/fork-notes.md`.

The directly affected implementation lives in the sibling repo `D:\ai-developer-toolkit`, specifically `plugins/ralph/`. Ralph is a plugin-style Node ESM codebase, not a package-managed app. Key structure:

- `plugins/ralph/src/*.mjs`: runtime Node ESM entrypoints and helpers.
- `plugins/ralph/scripts/*.mjs`: auxiliary Node scripts.
- `plugins/ralph/skills/**/SKILL.md`, `agents/*.md`, `.copilot-plugin/**`: Claude/Copilot-facing orchestration prose.
- `plugins/ralph/tests/`: mix of `node:test` `.mjs` tests and surviving bash tests.
- `plugins/ralph/.claude-plugin/plugin.json`: plugin manifest, currently `5.46.0`.
- `plugins/ralph/CHANGELOG.md` and `CLAUDE.md`: main release notes and maintainer guidance.

### Technical Constraints

- Runtime is now Node ESM. Normal migration target is:
  - `node plugins/ralph/src/codex-exec.mjs ...`
  - `node plugins/ralph/src/copilot-exec.mjs ...`
- Hermetic test env overrides remain valid:
  - `CODEX_EXEC_SCRIPT=/path/to/stub-codex.sh`
  - `COPILOT_EXEC_SCRIPT=/path/to/stub-copilot.sh`
  - Ralph detects extension and runs `.sh` overrides via bash.
- `tools/ralph.js` intentionally remains narrow (`--help`, `--version`) and should not become the migration entrypoint.
- No version bump is needed for doc-only work. If combined with a behavioral `--help` contract fix, version bumping would need the plugin manifests/indexes kept in sync.
- The work spans two repos: codexu for the audit report, ai-developer-toolkit for Ralph docs/code comments. Both worktrees are currently dirty, so implementation must avoid overwriting unrelated changes.
- `rg` was unavailable in this shell; `git grep` works well for tracked audit scopes.
