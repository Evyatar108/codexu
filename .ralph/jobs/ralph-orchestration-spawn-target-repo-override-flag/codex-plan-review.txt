### Feasibility

- [High] `AC-012` is not implementable as written. The proposed Phase 6 detection needs a wrapper repo root, but `implement-with-ralph/SKILL.md` Phase 6 currently only resolves `repo_root` inside the parallel PR handoff as the target repo from `prd.json.repoDir`. For a submodule-target job, that value is the submodule itself, so `git -C "$repo_root" submodule status -- <relative_repoDir>` will not detect that the submodule belongs to the wrapper. The plan should specify deriving the wrapper root from `job_dir` / `<wrapper>/.ralph/jobs/...`, then comparing `prd.json.repoDir` relative to that wrapper.

The overview says the topic branch is `ralph/plan-ralph-v5.49-bundle`, while the final spawn-prompt says `ralph/ralph-orchestration-spawn-target-repo-override-flag`.
