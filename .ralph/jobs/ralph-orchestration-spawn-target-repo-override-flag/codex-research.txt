**Codebase Architecture**

Ralph lives inside the `ai-developer-toolkit` submodule at `ai-developer-toolkit/plugins/ralph/`. It is a skills-only plugin with Markdown workflow specs plus zero-dependency Node ESM helpers.

Key structure:
- `plugins/ralph/skills/*/SKILL.md`: canonical Claude skill/workflow specs.
- `plugins/ralph/.copilot-plugin/...`: generated or hand-forked Copilot CLI mirrors.
- `plugins/ralph/src/*.mjs`: executable Node helpers, including `worktree-create.mjs`, `ralph.mjs`, `path-utils.mjs`.
- `plugins/ralph/scripts/*.mjs`: generation/parity tooling.
- `plugins/ralph/tests/`: `node:test` tests plus remaining bash smoke/prose tests.
- `plugins/ralph/AGENTS.md`: plugin operational docs, flags, release/version notes.
- Root `AGENTS.md`: codexu fork/bookkeeper/submodule ceremony guidance.

There is no `plugins/ralph/package.json`; tests are run directly, e.g. from `ai-developer-toolkit` with `node plugins/ralph/tests/run.mjs`.

**Technical Constraints**

- Canonical skill sources must stay synced with Copilot artifacts.
  - `convert-to-ralph-prd` is generated to `.copilot-plugin/internal-workflows/convert-to-ralph-prd/SKILL.md`.
  - `implement-with-ralph` has a hand-forked Copilot copy checked by `scripts/check-copilot-parity.mjs`.
- Before shipping Copilot artifacts, run:
  - `node plugins/ralph/scripts/generate-copilot-artifacts.mjs --check`
  - `node plugins/ralph/scripts/check-copilot-parity.mjs`
- `prd.json.repoDir` is schema-required but only string-validated by `src/ralph.mjs`; git repo validation belongs in conversion.
- Path output should follow existing normalized forward-slash convention.
- Feature says v5.49, but manifests currently show `5.47.0`; if this is a release, update all relevant plugin/version stamps and codexu active-plugin table when the submodule pointer changes.
- Pushes/remotes are lead-owned and ask-before-push per root `AGENTS.md`.
