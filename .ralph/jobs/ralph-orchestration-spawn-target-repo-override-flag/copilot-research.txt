### Codebase Architecture

`ai-developer-toolkit/plugins/ralph/` is a skills-only Ralph orchestration plugin. It has no local `package.json`; runtime helpers are zero-dependency Node ESM under `src/` and `scripts/`, while orchestration behavior is mostly specified in Markdown skills under `skills/`.

Key structure:
- `skills/implement-with-ralph/SKILL.md` — main user workflow.
- `skills/convert-to-ralph-prd/SKILL.md` — PRD-to-`prd.json` conversion and target repo/worktree setup.
- `src/worktree-create.mjs` — actual Node CLI helper for git worktree creation.
- `schemas/prd-schema.json` — `prd.json` schema; `repoDir` is required.
- `.copilot-plugin/` — Copilot mirror. Most internal workflows are generated by `scripts/generate-copilot-artifacts.mjs`; `implement-with-ralph` is a hand-fork guarded by `scripts/check-copilot-parity.mjs`.
- `tests/run.mjs` — auto-discovers `test-*.mjs`; some contract tests are Bash scripts.
