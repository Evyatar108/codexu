## Issue: Bulk copy does not inject preambles
**File:** D:\harness-efforts\codexu\.worktrees\overview-vite-react\tools\overview-viewer\src\hooks\useBulkSelection.ts:8
**Severity:** High
**Problem:** The `buildBulkCopyText` function concatenates raw `planPrompt` values without applying scope-based preambles (BOOKKEEPING_PREAMBLE, WORKTREE_PREAMBLE_CODEXU, etc.). This violates the stated requirement: "Bulk copy must concatenate the same preamble-injected copy-command output as per-row Copy Command."

Per-row copy (line 113 in TaskCommand.tsx) correctly calls `buildCopyCommandText(raw, task.scope)` which injects preambles. Bulk copy (line 8 in useBulkSelection.ts) uses `task.command?.planPrompt ?? ''` directly, skipping preamble injection entirely.

**Evidence:** 
- Single-task copy path: `CopyCommandButton` → `buildCopyCommandText()` → preambles injected via `buildCopyPreamble(parseTaskScope(scope))`
- Bulk copy path: `buildBulkCopyText()` → raw `planPrompt` → no preambles
- Test coverage (topLevelSurfaces.test.tsx:52-57) only validates task ordering, NOT preamble injection

**Suggested fix:** Import `buildCopyCommandText` and apply it per-task:
```typescript
.map((task) => `# === ${task.id} ===\n${buildCopyCommandText(task.command?.planPrompt ?? '', task.scope)}`)
