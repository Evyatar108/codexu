### Codebase Architecture

`codexu` is a pnpm monorepo with `ai-developer-toolkit\` as a submodule. Ralph Overview is implemented in `ai-developer-toolkit\plugins\ralph-overview\`, using npm workspaces:

- `scripts\lib\*.mjs`: sync, parsing, config, derived artifacts.
- `tools\overview-mcp\src\*.ts`: TypeScript MCP server.
- `tools\overview-viewer\src\*.ts(x)`: React 19 + Vite dashboard.
- Consumer data/config live in codexu at `.ralph-overview\data.json` and `.ralph-overview\config.json`.
- Codexu invokes the plugin through `bin\ralph-overview.mjs`, a resolver wrapper that forwards to the plugin dispatcher.

Generated overview artifacts are emitted under `.ralph-overview\generated\`, mainly by `scripts\lib\sync-core.mjs::writeSidecar()`.
