### Technical Constraints

The approved richer schema is not compatible with the current `buildReviewKindSummary()` result. Current output is `{ total, actionableCount, kinds, firstActionable, lastActionable, summary }`; target output is `headline`, `totalEntries`, `shownRows`, `senders`, lossless `counts`, full capped `actionable[]`, `needsActionCount`, and `truncatedActionable`.

Important invariants:

- `CREWS_REVIEW_MAIL_OVERVIEW=off` must omit overview on all three surfaces.
- Listener envelope must never include bodies or summaries; `messages === undefined` is pinned.
- Listener enrichment should be wrapped in `try/catch`; current code is not fail-open.
- Counts must use `collapsedCount || 1`, unlike current per-display-row `kinds`.
- Actionable policy must switch from allowlist to denylist: only progress/thread/member lifecycle notification kinds are non-actionable.
- Keep old exports as aliases for compatibility: `buildReviewKindSummary`, `flattenEntries`, `reviewOverviewEnabled`.

### Implementation Suggestions

Rewrite `lib/review-kind-summary.js` as the single policy module: export `NON_ACTIONABLE_KINDS`, `NEEDS_ACTION_KINDS`, `OVERVIEW_ACTIONABLE_CAP`, `parseOverviewEnv`, `computeReviewKindSummary`, and `expandMessagesToKindRecords`. Keep `buildReviewKindSummary()` as an alias to `computeReviewKindSummary()` and `reviewOverviewEnabled()` as `parseOverviewEnv().enabled`.

Wire `review-mail.js` and `/wake` to compute from already formatted `entries`, so collapsed fields and formatted summaries match what users see. Wire `listener-loop.js` as raw messages → `expandMessagesToKindRecords()` → `computeReviewKindSummary()`, then set `envelope.kinds = overview.counts` and `envelope.actionableCount`, inside fail-open `try/catch`.

Tests should explicitly add the missing 3+ actionable regression: e.g. `question@10`, `blocked@20`, `done@30` interleaved with progress all appear in `actionable[]`. Also add collapsedCount weighting, cap keeps last actionable, env-off byte-shape, and listener body-free/fail-open assertions.
