## Recommendations

1. **`prompts/codex.md` + `prompts/copilot.md`: enumerate the `evidenceKind` enum verbatim.** Right now both prompts mention `evidenceKind` (codex.md:151,155) without listing the legal values, and the iteration agent demonstrably invents off-schema values (`file-verified`, `test-pass`, `typecheck-pass`, `inspection`) — directly causing manifest-verifier to advisory-skip 3 of 9 iterations. Add an explicit list mirroring `schemas/iteration-result-schema.json:26-29` with one-line semantics for each value (`passed` = AC met with positive evidence, `absent-verified` = absence claim with cited negation-test command, `fallback` = degraded path documented, `skipped` = tool-unavailable warning, `manual-skip` = pre-approved criteriaWarning).

2. **`skills/analyze-iteration/SKILL.md` Step 0.5 and Step 7: add tool-unavailable fallback paths.** Both manifest-verifier (Step 0.5) and Refactoring Pass (Step 7) silently degrade when no Agent subagent tool is present in the orchestrator context — a recurring environmental condition for this user. Define `INLINE_FALLBACK` semantics for Step 0.5 (orchestrator runs minimum verification itself, emits a marker in `verifier-pass-fail-N.json` like `"runner": "inline-fallback"`) and `DEFERRED_REFACTOR` semantics for Step 7 (write `{ deferredRefactorAt: cumulativeCompleted }` into `analysis-result.json` so the next orchestrator run with a working subagent picks it up).

3. **`skills/review-plan-with-ralph/SKILL.md`: document the "inline Mediums into AC" convergence path as a first-class autonomous-mode step.** This job's PRD subagent independently decided to inline 9 unresolved Mediums into per-story AC bullets — the strategy worked (zero failures), but it's an emergent behavior documented only inside `notepad.md`. Make it explicit: when soft-cap fires in autonomous mode with N open Mediums of categories `Criteria Quality` or `Completeness`, the next phase MUST inline each finding's `suggestedFix` into the matching story's AC bullets with an `F-NNN:` tag prefix. Today this depends on the PRD subagent's independent reasoning, which is fragile across engine and model versions.

4. **`skills/implement-with-ralph/SKILL.md` Phase 5 (finalize): aggregate `Not-tested:` commit trailers into a single `manual-verification-todo.md`.** Three stories shipped with browser-flow gaps approved as `criteriaWarnings` in Phase 2.7. The only surviving trace post-merge is a `Not-tested:` line in each commit message — dispersed across the git log, easy to forget. The finalize phase should grep for `Not-tested:` trailers in this job's commits and write an aggregated TODO file an operator can work through.

5. **`docs/severity-rubric.md`: introduce `fixable-in-AC` as a sub-classification of Medium.** Findings of category `Criteria Quality` or `Completeness` whose `suggestedFix` is a one-paragraph AC clarification (rather than a structural plan change) should be classified `fixable-in-AC` from the start, so the plan-review loop doesn't burn fix-rounds editing markdown for changes that are better expressed as AC bullets. This collapses the observed pattern (9 Mediums → 6 review rounds → soft-cap → inlined anyway) into a single direct path.
