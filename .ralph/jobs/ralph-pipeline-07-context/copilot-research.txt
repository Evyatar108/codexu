### Codebase Architecture

Monorepo using **pnpm workspaces**. The relevant surfaces are:

- `scripts/lib/*.mjs`: Node ESM Ralph sync/sidecar pipeline.
- `tools/overview-viewer/`: Vite + React + TypeScript dashboard.
- `plans/overview-data.js`: hand-edited dashboard source.
- `plans/overview-ralph-state.js/json`, `plans/overview-snapshot.json`, `plans/overview-activity.jsonl`: generated Ralph artifacts.

The Ralph sync flow is centered on `scripts/lib/sync-core.mjs`: `walkRalphState()` reads `.ralph/jobs`, `.ralph/job-groups`, and `.ralph/brainstorms`; `assembleStateFromBundles()` matches slugs to overview tasks; `toPipelineState()` builds `RalphPipelineState`; `mergeAndWrite()` diffs state and returns `activityEvents`; `writeSidecar()` emits sidecars and agent artifacts. `scripts/lib/watch-ralph-state.mjs` owns the lock window and appends activity events after `mergeAndWrite()`.

The viewer reads `window.OVERVIEW_DATA` and `window.OVERVIEW_RALPH_STATE` in `tools/overview-viewer/src/App.tsx`, then renders command rows through `CommandList.tsx` → `TaskCommand.tsx` → `RalphStageChip.tsx`.
