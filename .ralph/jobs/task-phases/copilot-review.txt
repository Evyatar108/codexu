**Problem:** The `renderPhaseBadges()` IIFE only sets `cmd.dataset.taskStatus` when the legacy-derived status is `blocked` or `paused`, but not when it's empty string or would normalize to `ok`. **Evidence:** Line 1552 only writes `taskStatus` when `status === 'blocked' || status === 'paused'`, leaving rows with status `ok` or empty without the attribute.

**Suggested fix:** Add an `else` branch:

if (!cmd.dataset.taskStatus && (status === 'blocked' || status === 'paused')) {
