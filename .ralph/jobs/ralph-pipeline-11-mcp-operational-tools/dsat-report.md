1. **`C:/Users/evmitran/.claude/plugins/cache/ai-developer-toolkit/ralph-orchestration/5.41.0/agents/progress-analyst.md`** — Require literal-string evidence. Today the iteration agent silently substituted defaults (default-removed entries, `Promise.all`, 30-line tail, "sync already in progress") without flagging the substitution as a deferred question.
