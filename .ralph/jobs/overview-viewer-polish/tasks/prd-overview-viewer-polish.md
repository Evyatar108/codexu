# PRD: overview-viewer-polish

## Introduction / Overview

Polish + information-architecture restructuring of the `@codexu/overview-viewer` React app at `tools/overview-viewer/`. Five phases (A=pure CSS polish, B=toast+quick-actions+density, C=Radix UI primitives rollout, D=bucket headers + sticky top frame, E=left rail), totaling 19 stories. The seed at `plans/overview-viewer-polish-seed.md` is the canonical scope document; `plan.md` and `stories-outline.md` in this job directory are the binding inputs.

Generated by the Phase 2 PRD subagent on 2026-05-17 in autonomous mode. All clarifying questions were answered from the existing plan and stories outline.

## Goals

- Land all 5 phases (A through E) and a docs sweep, delivered as 19 small stories.
- Keep `plans/overview.html` bundle under 500 KB after every Radix phase build.
- Preserve the 3 existing intentional deviations from baseline `9f81c1f8` (phase-tree `deferred` class, blocked/paused → tail of phase bucket, `lastTouchedAt` ascending secondary sort).
- Honor `prefers-reduced-motion: reduce` for every new animation.
- Keep `file://` opens working — no service workers, no CDN fonts, no runtime CSS-in-JS injection.

## Non-Goals (Out of Scope)

- Bookkeeper-facing data mutations (viewer remains read-only).
- New SKILL.md procedures beyond the existing F + G.
- Migration of `plans/overview-data.js` to any new schema.
- Tailwind, CSS-in-JS, CSS modules, MUI, Chakra, Mantine, framer-motion, drag-and-drop, list virtualization, command palette (`cmdk`).
- New telemetry / analytics / service workers / external font fetching.

## Technical Considerations

- Single workspace package: `tools/overview-viewer/` (Vite + React 19.2 + TS, singleFile build via `vite-plugin-singlefile`).
- Generated artifact: `plans/overview.html` (current ~447 KB after F-011 fix). Hand-edited source of truth is `plans/overview-data.js`.
- Custom Vite plugin `overviewDataPlugin` in `tools/overview-viewer/vite.config.ts` serves + inlines `overview-data.js` and emits HMR event `overview-data:update`.
- localStorage namespace: `codexu-overview-<feature>-v<N>`.
- Bundle ceiling: 500 KB; halt Phase C rollout if exceeded.
- `interpolate-size: allow-keywords` is Chrome 129+ / Safari 17.4+ / FF 129+; fallback to instant snap.
- `animation-timeline: scroll()` is Chrome 115+ / Safari 18+; fallback to static toolbar shadow.
- `.kbd-help` has `z-index: 100` at `styles.css:592` — Radix Dialog portal z-index must be ≥ 100.
- vitest currently `environment: 'node'` with SSR-style render via `react-dom/server`; US-010 must install a verification harness (split-projects jsdom OR Playwright/agent-browser smoke) for Radix interaction stories.

## User Stories

### US-006: Install global prefers-reduced-motion guard (LANDS FIRST)
**Description:** As a viewer user with reduced-motion preference enabled, I want all current and future animations on the overview page to degrade to instant transitions so I don't get vestibular discomfort.

**Acceptance Criteria:**
- [ ] `tools/overview-viewer/src/styles.css` has a `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation: none !important; transition: none !important; } }` block placed immediately after the CSS variable definitions (top of file, before any animation rule).
- [ ] No existing tests regress.
- [ ] Typecheck passes.

**Dependencies:** None.
