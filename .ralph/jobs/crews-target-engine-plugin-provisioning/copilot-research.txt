### Codebase Architecture

`ai-developer-toolkit/plugins/crews` is a JavaScript-only plugin with no package-level `package.json`; runtime entry is `tools/crews.js`, which dispatches to command modules registered in `hooks/commands/registry.js`. Commands define `surfaces.slash` / `surfaces.cli`, parse with `tools/lib/parse-crew-args.js`, and run through `hooks/commands/runtime.js`.

Plugin packaging is multi-engine: `.claude-plugin/plugin.json`, `.github/plugin/plugin.json`, and `.codex-plugin/plugin.json`, plus marketplace indexes at `.claude-plugin/marketplace.json`, `.github/plugin/marketplace.json`, and `.agents/plugins/marketplace.json`. Skill files are generated by `plugins/crews/scripts/gen-skills.js`; version stamps are updated by `plugins/crews/scripts/bump-version.js`.
