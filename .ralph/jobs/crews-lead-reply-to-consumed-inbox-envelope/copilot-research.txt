### Codebase Architecture

`ai-developer-toolkit/plugins/crews` is a JavaScript-only plugin with no package-level `package.json`. Runtime code is organized around:

- `hooks/` — hook entrypoints and shared protocol/storage logic.
- `hooks/commands/` — slash/CLI command handlers like `send-to-member` and `review-mail`.
- `tools/crews.js` plus legacy tool shims — command dispatcher surfaces.
- `tests/*.test.js` and `tests/integration/*.test.js` — Node test files run by `node tests/run.js`.
- Plugin manifests in `.claude-plugin/`, `.github/plugin/`, `.codex-plugin/`, plus marketplace indexes at repo root.

### Feature-Relevant Code

Primary edit point is `hooks/mailbox.js`:

- `resolveReplySource(sender, replyTo, cwd)` currently handles:
  - member senders: searches sender inbox history via `getInboxHistoryPath`.
  - lead senders: searches lead send-history via `getSendHistoryPath`, then all member outboxes via `memberOutboxRowsIncludingLeftAt`.
