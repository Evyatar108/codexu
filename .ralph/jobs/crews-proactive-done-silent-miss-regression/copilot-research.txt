### Codebase Architecture

`ai-developer-toolkit\plugins\crews` is a JavaScript/CommonJS plugin with hook entrypoints under `hooks\`, CLI/slash command handlers under `hooks\commands\`, listener runtime in `lib\listener-loop.js`, and state persisted in `.crews` actor directories (`manifest.json`, `mailbox.json`, `mailbox-history.jsonl`, `outbox.jsonl`). Tests are plain Node scripts run by `node plugins/crews/tests/run.js`.

### Technical Constraints

`lastReviewedSeq` is the proof that the lead actually saw content. Listener delivery alone must not advance it unless the listener also carries/surfaces the terminal row content, which current v3.19 docs explicitly avoid. `readInboxHistorySince()` starts strictly after `lastReviewedSeq`, so once that cursor equals seq 501, `review-mail` cannot show seq 501.
