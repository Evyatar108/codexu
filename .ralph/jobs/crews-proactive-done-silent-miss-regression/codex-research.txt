**Codebase Architecture**
The crews plugin lives under [ai-developer-toolkit/plugins/crews](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews). It is a CommonJS Node.js plugin with no `package.json`; versioning is pinned in plugin manifests and checked by a custom test runner.

Key structure:
- [hooks/](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/hooks): engine hooks, mailbox/state primitives, Stop/UserPromptSubmit hooks.
- [hooks/commands/](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/hooks/commands): slash/CLI command implementations, including `review-mail`.
- [tools/](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/tools): CLI entrypoint/shims, especially `crews.js`.
- [lib/](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/lib): pure helpers, listener loop, review summary/collapse helpers.
- [tests/](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/tests): custom JS test files run by [tests/run.js](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/tests/run.js).

State is file-backed: actor manifests, `mailbox.json`, `mailbox-history.jsonl`, member `outbox.jsonl`, and cursors.

I verified current HEAD (`crews` 3.19.0) with a real watch-path reproduction: progress/progress/done produced listener stdout `via:"watch", count:1, kinds:{progress:2,done:1}`, then `review-mail` returned 3 entries and `advanced:true`. So the reported v3.14.1 failure is not reproducible in the current listener + review-mail path.

**Technical Constraints**
Preserve protocol v2 from `af07987d`: one durable outbox row per kind-bearing report tag, proactive non-reply delivery terminal-gated through `payload.entries`, no `progressTail` resurrection, and no first/last-tag collapse.

Do not break v3.6.2’s epoch guard in `consumeMailbox()` or v3.6.3’s display-only collapse in [lib/collapse-review-rows.js](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/lib/collapse-review-rows.js).

Cursor semantics matter: `consumedAt` means listener drained to history; `lastReviewedSeq` means the actor actually reviewed. Any path that advances `lastReviewedSeq` must surface the same expanded terminal content that `review-mail` would.

Version bumps must use [scripts/bump-version.js](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/scripts/bump-version.js) and update `.claude-plugin`, `.codex-plugin`, `.github/plugin`, and [tests/version.test.js](D:/harness-efforts/codexu/ai-developer-toolkit/plugins/crews/tests/version.test.js).
