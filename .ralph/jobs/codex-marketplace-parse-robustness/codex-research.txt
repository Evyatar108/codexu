**Codebase Architecture**
`ai-developer-toolkit` is a plugin marketplace repo inside `D:\harness-efforts\codexu\ai-developer-toolkit`. The root has no `package.json` or workspace file; tooling is intentionally per-plugin or plain scripts. Main areas:

- `plugins/`: plugin implementations, mixed Node/TS, C#, shell, and plugin manifests.
- `.claude-plugin/marketplace.json`: Claude Code marketplace.
- `.github/plugin/marketplace.json`: Copilot marketplace.
- `.agents/plugins/marketplace.json`: Codex repo-local marketplace.
- `.claude/skills/release-plugin/SKILL.md`: current plugin release gate.
- `docs/codex-plugins-local.md`: Codex plugin layout and maintenance notes.

Tests are not centralized. Existing lightweight patterns include plain CommonJS tests under `plugins/crews/tests/*.test.js` and shell-plus-inline-Node checks in `plugins/options-mode/tests/run.sh`.

**Technical Constraints**
No root Node package or test framework should be introduced. Keep the validator dependency-free and runnable with `node`.

The guard must be toolkit-only: no edits under `codex/`.

The Codex index schema differs from Claude/Copilot: only `.agents/plugins/marketplace.json` carries policy. The validator should treat missing `policy` as acceptable for policy-free indexes if invoked on all three files, while enforcing allowed values when policy fields are present or when validating the Codex index.

`release-plugin` currently says it “does not run tests” at line 191, so the plan should amend that text if the pre-flight begins invoking the validator.

**Implementation Suggestions**
Add a small root-level script/module, for example:

- `tools/validate-codex-marketplace-policy.mjs`
- `tools/validate-codex-marketplace-policy.test.mjs`
- `tools/fixtures/marketplace-policy-valid.json`
- `tools/fixtures/marketplace-policy-invalid-auth-off.json`

Use one exported constant:

```js
export const CODEX_MARKETPLACE_POLICY_ENUMS = {
  installation: ['NOT_AVAILABLE', 'AVAILABLE', 'INSTALLED_BY_DEFAULT'],
  authentication: ['ON_INSTALL', 'ON_USE'],
};
```

Put the `marketplace.rs` coupling comment directly above that constant.

Make the CLI accept file paths, defaulting to `.agents/plugins/marketplace.json` plus optionally the two policy-free indexes. Error messages should include plugin name, field path like `plugins[crews].policy.authentication`, bad value, and accepted values.
