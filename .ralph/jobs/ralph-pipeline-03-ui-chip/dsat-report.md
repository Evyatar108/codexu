## Recommendations
1. **`prompts/claude.md` — verifiedEvidence schema clarity.** Embed the closed enum for `evidenceKind` (`passed|skipped|manual-skip|fallback|absent-verified`) with one literal example per value. Embed the `skippedReasons` object shape (`[{criterion, reason, evidence}]`) with a literal JSON example. Today's prompt is permissive enough that the codex iteration agent emits `static-inspection`/`command-output`/`test-output` and string-array `skippedReasons`, silently disabling the manifest verifier in 5 of 7 iterations.
2. **`skills/review-plan-with-ralph/SKILL.md` — soft-cap open-Medium ledger.** When soft-cap fires (here at iter 5 with 7 open Mediums), persist the open Mediums to a discoverable file (`plan-review-open-mediums.md`) and require the iteration agent to address relevant items as verifiedEvidence on the matching story. Today F-005 (missing transformIndexHtml guard), F-006 (role=button accessibility), and F-007 (positive-path filter test) were "folded into notes" — which only worked because the orchestrator hand-curated story notes. Make this an artifact, not a prose handoff.
3. **`agents/docs-reviewer.md` — sweep inventory blocks once.** When a Stale-Documentation finding lands on an inventory/layout/index block, scan the entire block once and emit all instances in one round. F-001 and F-003 in `docs-review-findings.json` are the same staleness shape on sibling lines of `tools/overview-viewer/CLAUDE.md`; surfacing them in separate rounds cost a full convergence cycle.
4. **`skills/implement-with-ralph/SKILL.md` — Phase 2.7 → PRD bridge for tool-availability warnings.** The criteria validator surfaced 8 browser-DOM ACs as tool-availability warnings up front. Today the iteration agent independently rediscovered "use jsdom interaction tests under `src/__tests__/interactions/`" four times (US-002, US-003, US-004, US-006). Have Phase 2.7 auto-annotate flagged ACs with the fallback strategy directly in `prd.json` so the iteration agent doesn't re-derive it per story.
5. **`skills/analyze-iteration/SKILL.md` — Refactoring Pass DEFERRED needs a discoverable artifact.** When the Refactoring Pass is deferred due to parallel-work guardrails or any other reason, write a one-line rationale to `refactor-deferred.md` (or append to `notepad.md` under a stable heading). Today the rationale lives only inside `progress.txt`'s Orchestrator Notes prose, which a future analyst or sibling crew member cannot reliably find.
6. **`prompts/claude.md` — progress.txt timing line.** Either drop the redundant `Time: …ms` line from the per-story progress.txt template (single source of truth = `metrics.json`/`iteration-result-N.json`) or require the agent to copy `time_ms` from the iteration-result JSON it just wrote. Iters 5 and 7 in this job logged "Time: not recorded by agent" while `metrics.json` has the actual values.
