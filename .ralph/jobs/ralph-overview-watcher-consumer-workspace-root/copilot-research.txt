### Feature-Relevant Code

The root bug is repo-root detection drifting to the plugin install/cache root.

Key files:

- `scripts\sync-ralph-state.mjs`
  - `main()` uses `args.repo ? path.resolve(args.repo) : resolveRepoRoot()`.
  - `resolveRepoRoot()` currently only runs `git rev-parse --show-toplevel` from current cwd.
- `scripts\lib\watch-ralph-state.mjs`
  - `start({ repoRoot })` requires caller-supplied repo root.
  - `getWatcherOwnerPath(repoRoot)` writes `<repoRoot>\.ralph\overview-watcher.owner`.
- `tools\overview-mcp\src\context.ts`
  - `buildContext(repoRoot = resolveRepoRoot(process.cwd()))`.
  - Current `resolveRepoRoot(cwd)` uses git root or cwd, so Copilot launching from plugin cache resolves the plugin/cache as the repo.
- `tools\overview-mcp\src\watcher-supervisor.ts`
  - Defaults `ownerPath` from `getWatcherOwnerPath(context.repoRoot)`.
  - Spawns `bin\ralph-overview.mjs sync --repo <context.repoRoot> --watch`.
- `tools\overview-viewer\vite.config.ts`
  - Has another local `resolveRepoRoot()`: `OVERVIEW_REPO_ROOT`, then git root, then cwd.
  - `ralphStateWatcherPlugin()` defaults watcher repo root through that local helper.
- `launch.cjs`
  - Preserves `cwd: process.cwd()` when spawning MCP dist, but Copilot may set cwd to the installed plugin/cache path.
- `D:\harness-efforts\codexu\bin\ralph-overview.mjs`
  - Already injects `--repo <consumer git root>` for `pnpm overview`, which protects the Claude/manual path.

### Technical Constraints

`loadConfig({ repoRoot })` requires a repo root and defaults to `<repoRoot>\.ralph\overview-config.json`; if repo root is wrong, config and outputs all point wrong. Missing Ralph subdirs only warn, so wrong-root startup can still proceed far enough to write owner markers/sidecars in plugin cache.

Owner marker semantics are important: the watcher child must atomically claim `<repoRoot>\.ralph\overview-watcher.owner`; the MCP supervisor should not pre-write it. Existing multi-MCP coordination tests depend on `openSync('wx')`, `.claim` files, and passive peer behavior.

There is no existing `scripts\lib\repo-root.mjs`; repo-root logic is duplicated in `sync-ralph-state.mjs`, `context.ts`, `vite.config.ts`, and `install-server.ts`.
