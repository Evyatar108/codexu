**Technical Constraints**

The biggest constraint: do not add a `skills` array. The actual manifest shape is `skills: Option<String>`, and the existing plugin already uses `"skills": "./skills"`. Adding per-skill manifest entries would be wrong; Codex discovers every `SKILL.md` under that one root.

Path constraints from the roadmap’s manifest notes:

- `skills` must start with `./`.
- Absolute paths and `..` are rejected.
- Unknown manifest fields are silently ignored.
- Malformed JSON or wrong field types can make the plugin absent or drop fields with only log warnings.
