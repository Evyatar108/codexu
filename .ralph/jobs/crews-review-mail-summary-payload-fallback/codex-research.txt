## Codebase Architecture

`D:/ai-developer-toolkit/plugins/crews` is a pure Node.js CommonJS plugin. There is no plugin-local `package.json`; tests run through the custom runner at `plugins/crews/tests/run.js`, not `npm test`.

Key structure:

- `hooks/*.js`: engine hook entrypoints, especially [stop.js](D:/ai-developer-toolkit/plugins/crews/hooks/stop.js).
- `hooks/commands/*.js`: slash/CLI command handlers, including [review-mail.js](D:/ai-developer-toolkit/plugins/crews/hooks/commands/review-mail.js).
- `hooks/mailbox.js`: mailbox/outbox/history primitives, re-exported through `hooks/config.js`.
- `tools/*.js` and `tools/crews.js`: CLI shims/dispatcher.
- `tests/*.test.js` and `tests/integration/*.test.js`: direct unit-ish tests plus scenario harness in `tests/integration/lib/scenario.js`.
- State model is file-based under `.crews/crews/<crew>/members|leads/<actor>/`, with `mailbox.json`, `mailbox-history.jsonl`, `outbox.jsonl`, manifests, and send history.

## Feature-Relevant Code

The read bug is in [review-mail.js](D:/ai-developer-toolkit/plugins/crews/hooks/commands/review-mail.js): `formatReviewMailEntry()` currently returns:

```js
summary: row && row.summary !== undefined ? row.summary : null,
```

This ignores `row.payload.summary`.

The write-side asymmetry is in [stop.js](D:/ai-developer-toolkit/plugins/crews/hooks/stop.js):

- member reply path around `appendSystemMailbox(... { kind: tags.kind, message, payload: { ... summary: effectiveSummary } } ...)`
- proactive report path around `appendSystemMailbox(... { kind: tags.kind, message, payload } ...)`

[mailbox.js](D:/ai-developer-toolkit/plugins/crews/hooks/mailbox.js) preserves arbitrary envelope fields passed to `appendSystemMailbox()`, then `consumeMailbox()` copies the envelope into `mailbox-history.jsonl` with `seq`, `receivedAt`, `consumedAt`, and `via`. So the correct write-side integration point is the two `stop.js` call sites, not `mailbox.js`.

Note: `D:/ai-developer-toolkit/plugins/crews/hooks/lib/inbox-history.js` does not exist in this checkout. The relevant implementation is `hooks/mailbox.js`.
