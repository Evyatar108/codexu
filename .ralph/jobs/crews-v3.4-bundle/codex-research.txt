## Codebase Architecture

The relevant code lives in the `ai-developer-toolkit` git submodule, specifically `ai-developer-toolkit/plugins/crews/`.

`crews` is a Node.js hook/plugin package, not an npm package in this checkout: there is no `package.json` under `plugins/crews`. Tests are plain Node scripts run by `plugins/crews/tests/run.js`.

Key structure:

- `hooks/` — runtime hook logic for SessionStart, PreToolUse, Stop, listener protocol, mailbox/config helpers.
- `hooks/crews.js` — CLI dispatcher used by commands like `arm`, `status`, `review-mail`.
- `hooks/listener-protocol.js` — listener command construction and listener-arm detection.
- `hooks/detect-active-bg.js` — Copilot async background process detector used by the progress-bg Stop gate.
- `hooks/stop.js` — Stop hook gate orchestration, including listener reachability and progress-bg checks.
- `hooks/pre-tool-use.js` — PreToolUse listener-arm gate; this is why `isListenerArmCall` must stay narrow.
- `tests/` — plain Node regression tests plus shared helpers in `tests/lib/`.
- `AGENTS.md`, `CHANGELOG.md` — protocol docs and release notes.
- `scripts/bump-version.js` — bumps crews version across manifests, marketplace indexes, and `tests/version.test.js`.

The codexu root tracks the submodule pointer and has an active plugin version table in `AGENTS.md`.

## Technical Constraints

- Keep `isListenerArmCall()` narrow. `pre-tool-use.js` relies on it for permissioning listener arms through the arm-first gate.
- `detect-active-bg.js` currently names the sample field `isListener`. If it starts filtering all crews CLI infrastructure, either keep the field for minimal blast radius or rename carefully with test updates. Minimal scope favors keeping it.
- Stop hook ordering matters: listener reachability is evaluated before the progress-bg gate.
- Lead prose-only turns are synthesized as `kind='progress'` in `stop.js` lines 889-903, so `shouldRequireArmedListener({ role:'lead', kind:'progress', queueDepth:0 })` must become true.
- For strict manifest tests, `listenerState:'exited'` requires `lastListenerExitedAt`; `listenerState:'armed'` requires `lastListenerSpawnAt`.
- Version bump should use `node plugins/crews/scripts/bump-version.js 3.4.0` from `ai-developer-toolkit/`. It updates both plugin manifests, three marketplace indexes, and `tests/version.test.js`.
- Codexu root `AGENTS.md` active plugin versions table must be updated when the submodule pointer is bumped.
